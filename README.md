# 10x10 삼목

10×10 판에서 흑과 백이 번갈아 돌을 두어, 가로·세로·대각선으로 자기 돌 3개를 먼저 잇는 쪽이 이기는 두 사람용 게임입니다.

- `index.html` 파일 하나로 동작합니다. 브라우저로 열거나 GitHub Pages로 배포하면 됩니다.
- 외부 라이브러리·외부 글꼴·분석 도구를 쓰지 않고, `Content-Security-Policy`가 외부 연결을 모두 막습니다.

## 규칙

- 흑이 먼저 두고, 이후 번갈아 빈 칸(교차점)에 한 수씩 둡니다.
- 방금 둔 돌을 포함해 한 방향으로 같은 색 돌이 3개 이상 이어지면 이깁니다.
- 승자 없이 100칸이 모두 차면 무승부입니다.
- **무르기**는 마지막 한 수를 취소합니다. 게임이 끝난 뒤에도 쓸 수 있습니다.

## 조작

- 마우스·터치: 칸을 누르면 둡니다.
- 키보드: 방향키로 칸을 옮기고(Home·End는 줄 처음·끝) Enter나 Space로 둡니다.

설계는 [docs/PLAN.md](docs/PLAN.md)에 있습니다.

## 시험

의존성 없이 Node.js 20 이상에서 실행합니다.

```bash
npm test
```

- `test/game.test.mjs`: `index.html`의 `<script id="game-core">` 블록(게임 로직)만 꺼내 DOM 없는 환경에서 시험합니다.
- `test/static.test.mjs`: 외부 주소·네트워크·저장 API가 없는지, CSP가 있는지 검사합니다.
