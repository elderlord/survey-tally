# survey-tally

엑셀에서 머리글 줄까지 복사해 붙여넣으면 문항별 결과 표(유효 응답 / 평균 / 빈 응답 / 제외)를 보여 주는 설문 집계기입니다.

- `index.html` 파일 하나로 동작합니다. 브라우저로 열거나 GitHub Pages로 배포하면 됩니다.
- 외부 라이브러리·외부 글꼴·분석 도구를 쓰지 않습니다.
- 붙여넣은 데이터는 브라우저 안에서만 계산하며, 어디로도 보내거나 저장하지 않습니다.
  `Content-Security-Policy`가 외부 연결을 모두 막습니다.

## 집계 규칙

- 첫 열(응답번호)은 집계하지 않습니다.
- 칸의 앞뒤 공백을 지운 값이
  - `1`~`5` 중 하나면 **유효**
  - 비었거나 공백만 있으면 **빈 응답**
  - 그 밖의 값이면 **제외**
- 칸 수가 머리글보다 모자란 줄은 모자란 칸을 빈 응답으로 셉니다. 머리글보다 많은 칸은 무시합니다.
- 평균은 유효 응답의 합 ÷ 유효 응답 수를 셋째 자리에서 반올림해 둘째 자리까지 보입니다. 유효 응답이 없으면 `-`입니다.

자세한 설계는 [docs/PLAN.md](docs/PLAN.md)에 있습니다.

## 시험

의존성 없이 Node.js 20 이상에서 실행합니다.

```bash
npm test
```

- `test/tally.test.mjs`: `index.html`의 `<script id="tally-core">` 블록(계산 로직)만 꺼내 DOM 없는 환경에서 시험합니다.
- `test/privacy.test.mjs`: 외부 주소·네트워크·저장 API가 없는지, CSP가 있는지 검사합니다.
