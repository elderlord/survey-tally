# 설문 집계기 계획서

## 목표

엑셀에서 머리글 줄까지 복사해 붙여넣으면 문항별 결과 표를 보여 주는 단일 `index.html`.

## 제약

- 파일은 `index.html` 하나. 외부 라이브러리·외부 글꼴·분석 도구를 쓰지 않는다.
- 붙여넣은 데이터는 브라우저 밖으로 보내지도, 저장하지도 않는다.
  - 네트워크 요청 API(`fetch`, `XMLHttpRequest`, `sendBeacon`, `WebSocket` 등)와
    저장 API(`localStorage`, `sessionStorage`, `indexedDB`, 쿠키)를 쓰지 않는다.
  - `Content-Security-Policy`를 `default-src 'none'`으로 두어 외부 연결을 브라우저가 막게 한다.
  - 입력란은 `spellcheck="false"`, `autocomplete="off"`로 둔다
    (일부 브라우저의 고급 맞춤법 검사는 입력 내용을 서버로 보낸다).
- 저장소 맨 위에 빈 `.nojekyll` 파일을 둔다(GitHub Pages가 Jekyll 처리를 건너뛰게).

## 집계 규칙

| 항목 | 규칙 |
|---|---|
| 입력 | 탭으로 칸, 줄바꿈(`\r\n`, `\n`, `\r`)으로 줄을 나눈다. 첫 줄은 머리글. |
| 따옴표 | 엑셀은 탭·줄바꿈·따옴표가 든 칸을 `"…"`로 감싸고 `"`를 `""`로 적는다. 이를 풀어 읽는다. |
| 첫 열 | 응답번호이므로 집계하지 않는다. 둘째 열부터가 문항이다. |
| 유효 | 앞뒤 공백을 지운 값이 `1`·`2`·`3`·`4`·`5` 중 하나 |
| 빈 응답 | 비었거나 공백만 있는 칸 |
| 제외 | 그 밖의 모든 값(`6`, `0`, `3.0`, `a`, 전각 `３` 등) |
| 모자란 칸 | 칸 수가 머리글보다 적은 줄은 모자란 칸을 빈 응답으로 센다 |
| 남는 칸 | 머리글보다 많은 칸은 속한 문항이 없으므로 무시한다 |
| 평균 | 유효 응답의 합 ÷ 유효 응답 수를 셋째 자리에서 반올림(0.5는 올림)해 둘째 자리까지. 유효가 0이면 `-` |
| 앞뒤 빈 줄 | 엑셀 복사 끝에 붙는 줄바꿈 등, 입력 맨 앞·맨 뒤의 완전히 빈 줄은 버린다. 가운데 빈 줄은 응답 줄로 보고 모두 빈 응답으로 센다. |

평균은 부동소수점 오차(예: `1.005`가 `1.00`이 되는 문제)를 피하려고 정수 연산으로 구한다:
`q = floor((합 × 200 + 수) / (2 × 수))` → `q / 100`을 두 자리로 표시.

## 구조

- `index.html`
  - `<script id="tally-core">`: 계산 로직만. DOM을 건드리지 않고 `globalThis.SurveyTally`에
    `parseTsv`, `classifyCell`, `formatAverage`, `tally`를 내놓는다.
  - 그 아래 별도 `<script>`: 화면(입력란, 결과 표, 오류 안내)만 담당하고 `SurveyTally.tally`를 호출한다.
- `test/tally.test.mjs`: `index.html`에서 `tally-core` 블록을 꺼내 `node:vm`의 빈 환경에서 실행하고
  로직을 시험한다(DOM이 없는 환경이므로 로직이 화면과 떨어져 있음도 함께 보장된다).
- `test/privacy.test.mjs`: `index.html`에 외부 주소·네트워크·저장 API가 없는지, CSP가 있는지 정적으로 검사한다.
- `package.json`: 의존성 없이 `npm test` → `node --test`.
- `.github/workflows/test.yml`: 푸시·PR마다 시험 실행.
